# Security policy

## Reporting a vulnerability in PayPilotLabs Telephony
Report it privately through GitHub's [private vulnerability reporting](https://github.com/paypilotlabs/paypilotlabs-telephony/security/advisories/new). Do not open a public issue.

- Include: affected version or commit, steps to reproduce, and the impact.
- We acknowledge within 3 business days and send a status update within 10.
- We credit you in the advisory unless you prefer not to be named.

## Supported versions
Only the latest commit on `main` receives security fixes.
