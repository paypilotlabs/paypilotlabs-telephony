# Contributing to PayPilotLabs Telephony

Thanks for helping. PayPilotLabs Telephony is maintained by [PayPilotLabs](https://paypilotlabs.com).

## How to contribute
1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Fork the repo and create a branch from `main`. Outside contributors never get write access; all changes come through a pull request from a fork.
3. Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages and the PR title (`fix: ...`, `feat: ...`).
4. Run it locally with Docker (see README → Run it) and check your change works.
5. Open the pull request and fill in the template. CI must pass, and a code owner reviews and merges.

## Ground rules
- Keep the existing licence and copyright headers. New files you add are under this repo's licence.
- Never commit secrets, `.env` files or site config with passwords.
- Security issues go through [private vulnerability reporting](SECURITY.md), never a public issue.
- Be kind: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
